Mahjong Tile Pad

麻雀牌パッド

Type and copy mahjong tiles

麻雀牌を文字で入力してコピー

Mahjong Tile Pad is a simple app for typing and copying mahjong tiles as text.

You can quickly build a tile string and copy it when you want to share hands or notes.

Mahjong Tile Pad は、麻雀牌を文字で入力してコピーできるシンプルなアプリです。

手牌やメモを文字で手早く作って、すぐにコピーして使えます。

Features Features

Main Features 主な機能

  • Tap tiles to add them
  • Copy all tiles instantly
  • Tap Del to remove the last tile
  • Long press Del to clear all
  • Supports both portrait and landscape layouts
  • Open Help from the ? button
  • 牌をタップして入力
  • Copyで牌をまとめてコピー
  • Delで最後の牌を削除
  • Del長押しで全消去
  • 縦画面・横画面に対応
  • ？から使い方を確認可能
